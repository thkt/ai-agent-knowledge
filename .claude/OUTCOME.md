# OUTCOME

## Outcome state

### Behavior

- thkt は、開発の考え方と進め方を、このリポジトリの記録(外部の資料の照合、自分で確かめた結果、考察)に基づいて決めている。決めた考え方は、cantle と dotclaude などのハーネスの Issue か変更になり、このリポジトリのページから反映先を辿れる。
- チームメンバーは、AIエージェント運用上の判断(ルールを追加するか、どのツールを使うか、など)について、このリポジトリを読んで採用した理由と却下した案を説明できる。
- 読者は、各知見の検証日・検証したモデル・再現手順を読み取り、その知見が現在のモデルとツールで再現するかを自分で判定できる。

## Non-goals

- エージェントが読み込む設定(rules / skills)の正本を置くこと。正本は `~/.claude` に残す。
- 特定ツールの使い方を網羅する手順書を作ること。使い方は公式ドキュメントに任せる。
- 社外の読者に向けて説明や体裁を整えること。リポジトリは公開しているが、想定する読み手は社内のメンバーと将来の自分である。

## Constraints

- このリポジトリは公開されている。顧客名・案件名・認証情報など、社内の機密にあたる内容を書かない。
- 他人の記事や投稿の原文を転載しない。要点の要約とリンクで扱う。
- commit のメールアドレスには、GitHub の noreply のアドレスを使う。
- 本文は日本語で書く。識別子・コマンド・固有名詞は原語のまま書く。
- Markdown ファイルだけで構成する。ビルドなしで GitHub 上で読める状態を保つ。
