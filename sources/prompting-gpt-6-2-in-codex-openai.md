# OpenAI の、Codex で GPT-6.2 系に頼むときの書き方の手引き（2026-11）

OpenAI の ChatGPT Learn は、Codex で GPT-6.2 系のモデル（Astra と Sol）に頼むときの書き方を、4 つの節で説明する。手引きの本文を、手元の指示のファイルと、自分のプロジェクトで数えたテストの失敗に当てはめた。手引きに測定は無く、自分たちで確かめた判断でもない。

## TL;DR

- 中心の助言は 2 つある。プロジェクトを知っている同僚に頼むように書く。成果物をレビューするときに何を確認するかを、先に伝える。

## 中心の主張

**何を作るかに加えて、できたものをどう確かめるかを伝える。** 手引きは、小さいアイコンの例を挙げる。24 ピクセルのツールバーで見分けられる必要があるなら、その条件を書く。モデルは、既存のアイコンから様式を読み取り、その大きさで見分けられる細かさを自分で決める。
