# トヨタ生産方式の公式の説明：異常で止めることと、引き取られた分だけ作ること（2026-11）

トヨタ自動車は、企業サイトでトヨタ生産方式の考え方を説明している。頁の全文を読み、同じ日に手元で扱っていた agent の進め方と突き合わせた。頁はソフトウェアにも agent にも触れていない。突き合わせは、照合者の当てはめである。自分たちが採用した判断ではない。

## TL;DR

- 目的は、働く人を楽にすることを前提に、注文された車を、良い品質で、安く、早く届けることである。手段は、ムダを無くすことと、リードタイムを短くすることである。
- 柱は 2 つある。自働化は、異常で止めて不良を後ろへ流さない。ジャスト・イン・タイムは、後の工程が引き取った分だけを作り、物と情報を停滞させない。
- 自働化には順番がある。機械を作る前に、手作業でやって改善し、異常を見つけられるようにしてから、機械に組み込む。
- 頁に、効果の数字と、うまくいかなかった例は無い。照合日は 2026-11-23。
- 手元の進め方に当てると、「引き取られた分だけ作る」は、利用で起きた要求だけを Issue にする決まりに当たる。「手作業が先」は、決まりを skill の文にする前に、手で回すことに当たる。

## 中心の主張

**不良を作らないことと、作りすぎないことを、仕組みに組み込む。** 頁は、この 2 つを「自働化」と「ジャスト・イン・タイム」と呼び、どちらも人の改善の積み重ねから作ると書く。

## 考え方と根拠

| 考え方 | 頁の記述 | 照合の結果 |
